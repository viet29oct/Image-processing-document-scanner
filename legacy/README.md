# legacy/

Các bài lab đã làm trước khi chốt đề tài (Ch2–Ch3: chuyển ảnh xám, lấy ngưỡng đơn giản/Adaptive/Otsu, tách kênh màu, biến đổi tuyến tính/gamma, tương quan). Giữ nguyên làm tham khảo; **không sửa, không import vào `src/`**.

- `labs/code/`: script Python
- `labs/source/`: ảnh đầu vào và ảnh kết quả

Một số script có thể dùng đường dẫn ảnh theo máy của người viết; chạy lại thì chỉnh đường dẫn.
